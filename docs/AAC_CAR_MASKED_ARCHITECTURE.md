# AAC-Car-Masked Pipeline Architecture

**Status**: Design (Ready for Implementation)  
**Scope**: Standalone noise-masking pipeline for car audio libraries  
**Input**: ALAC files from MUSAEUS  
**Output**: 256kbps AAC files with noise masking applied  
**Schedule**: Next session (post-Task 2.4)

---

## Overview

**AAC-Car-Masked** is an optional, **standalone pipeline** that takes high-fidelity ALAC audio files produced by MUSAEUS and:
1. Applies noise-masking profiles (clean, pink, brown, white, dual) to simulate car audio environments
2. Encodes to 256kbps AAC for car-friendly formats
3. Exports to a car-library directory structure

**Key Characteristics:**
- Runs **independently** (not part of nightly pipeline)
- Used **1–2 times per year** for car library updates
- Takes **ALAC files** as input (generated by MUSAEUS)
- Produces **car-ready AAC files** with environment masking
- Fully **reversible** (source ALAC files preserved)

---

## Design Principles

1. **Non-invasive**: Doesn't modify MUSAEUS core or nightly workflows
2. **Deterministic**: Same input → same output (reproducible)
3. **Modular**: Can be invoked standalone or integrated into MUSAEUS later
4. **Reversible**: No destructive operations; always has source backup
5. **Configurable**: Profiles, bitrate, output path all customizable
6. **Observable**: Comprehensive logging and progress reporting

## Pipeline Architecture

```
AAC-Car-Masked Pipeline
│
├─ Input: ALAC Files (from MUSAEUS)
│  └─ /mnt/FORGE2TB/Projects/MUSAEUS_OUTPUT/ALAC/
│
├─ Stage 1: Discovery
│  ├─ Scan ALAC directory
│  ├─ Count files
│  └─ Validate audio format
│
├─ Stage 2: Noise Profile Generation (One-time)
│  ├─ Generate noise profiles:
│  │  ├─ clean (no masking)
│  │  ├─ pink (balanced frequency)
│  │  ├─ brown (low-frequency heavy)
│  │  ├─ white (equal power all freqs)
│  │  └─ dual (pink + white blend)
│  └─ Store profiles: /tmp/aac_car_profiles/
│
├─ Stage 3: Audio Processing (Per File)
│  ├─ Read ALAC file
│  ├─ Apply noise masking (selected profile)
│  ├─ Normalize loudness (to -14 LUFS for car)
│  ├─ Encode to AAC 256kbps
│  └─ Write to output directory
│
├─ Stage 4: Library Assembly
│  ├─ Organize by Artist/Album
│  ├─ Copy metadata
│  ├─ Create playlists (optional)
│  └─ Generate manifest
│
└─ Output: Car Library
   └─ /mnt/FORGE2TB/Projects/ORPHEUS_CAR_LIBRARY/
      ├─ Artist1/Album1/*.m4a (256k AAC)
      ├─ Artist2/Album2/*.m4a
      └─ manifest.json
```

### 1. Discovery Module (`discovery.py`)

**Purpose**: Scan and validate input ALAC files

```python
class CarMaskedDiscovery:
    def __init__(self, alac_root: Path):
        self.alac_root = alac_root
    
    def scan_alac_files(self) -> list[Path]:
        """Recursively find all .alac files."""
        return list(self.alac_root.rglob("*.alac"))
    
    def validate_format(self, path: Path) -> bool:
        """Check if file is valid ALAC."""

    def count_by_artist(self) -> dict[str, int]:
        """Group file counts by artist."""
    
    def estimate_output_size(self, file_list: list[Path]) -> int:
        """Estimate total size in bytes for 256k AAC output."""
```

```python
class NoiseProfileGenerator:
```

### 3. Audio Processor Module (`processor.py`)

**Purpose**: Apply noise masking and encode

```python
class CarMaskedAudioProcessor:
    def __init__(self, output_dir: Path, profile_id: str = "pink"):
        self.output_dir = output_dir
        self.profile_id = profile_id
    
    def process_file(self, alac_path: Path) -> dict:
        """
        1. Read ALAC
        2. Apply noise masking
        3. Normalize to -14 LUFS
        4. Encode to 256k AAC
        5. Write to output
        
        Returns: {
            'input_path': Path,
            'output_path': Path,
            'duration_s': float,
            'loudness_lufs': float,
            'success': bool,
            'error': str or None,
        }
        """
    
    def _apply_noise_masking(self, audio: np.ndarray, sr: int, profile_id: str) -> np.ndarray:
        """Apply noise overlay to audio signal."""
    
    def _normalize_loudness(self, audio: np.ndarray, sr: int, target_lufs: float = -14.0) -> np.ndarray:
        """Use pyloudnorm to normalize to target loudness."""
    
    def _encode_aac(self, audio: np.ndarray, sr: int, output_path: Path, bitrate_k: int = 256) -> bool:
        """Encode to AAC using ffmpeg."""
```

### 6. Main Pipeline Module (`pipeline.py`)

**Purpose**: Orchestrate all stages

```python
class CarMaskedPipeline:
    def __init__(
        self,
        alac_root: Path,
        output_root: Path,
        profile_id: str = "pink",
        bitrate_k: int = 256,
        workers: int = 4,
    ):
        self.alac_root = alac_root
        self.output_root = output_root
        self.profile_id = profile_id
        self.bitrate_k = bitrate_k
        self.workers = workers
    
    def run(self, dry_run: bool = False) -> dict:
        """
        Execute full pipeline:
        1. Discovery
        2. Generate noise profile
        3. Process files (parallelized)
        4. Assemble library
        5. Create manifest
        
        Returns: {
            'status': 'success' | 'partial' | 'failed',
            'files_processed': int,
            'files_failed': int,
            'output_size_mb': float,
            'duration_seconds': float,
            'manifest_path': Path,
        }
        """
    
    def estimate_duration(self) -> float:
        """Estimate total processing time."""
    
    def estimate_output_size(self) -> int:
        """Estimate total output size."""
```

## CLI Entry Point (`build_aac_car_masked.py`)

```python
#!/usr/bin/env python3

import argparse
from pathlib import Path
from musaeus.car_masked.pipeline import CarMaskedPipeline

def main():
    parser = argparse.ArgumentParser(description="Build AAC-Car-Masked library")
    parser.add_argument(
        "--alac-root",
        type=Path,
        default=Path("/mnt/FORGE2TB/Projects/MUSAEUS_OUTPUT/ALAC"),
        help="Root directory of ALAC files from MUSAEUS",
    )
    parser.add_argument(
        "--output-root",
        type=Path,
        default=Path("/mnt/FORGE2TB/Projects/ORPHEUS_CAR_LIBRARY"),
        help="Output directory for car-ready AAC library",
    )
    parser.add_argument(
        "--profile",
        choices=["clean", "pink", "brown", "white", "dual"],
        default="pink",
        help="Noise masking profile",
    )
    parser.add_argument(
        "--bitrate",
        type=int,
        default=256,
        help="AAC bitrate in kbps",
    )
    parser.add_argument(
        "--workers",
        type=int,
        default=4,
        help="Parallel workers for encoding",
    )
    parser.add_argument(
        "--preview",
        action="store_true",
        help="Dry-run: estimate without processing",
    )
    parser.add_argument(
        "--apply",
        action="store_true",
        help="Execute (default: dry-run)",
    )
    args = parser.parse_args()

    pipeline = CarMaskedPipeline(
        alac_root=args.alac_root,
        output_root=args.output_root,
        profile_id=args.profile,
        bitrate_k=args.bitrate,
        workers=args.workers,
    )

    if args.preview:
        print(f"Preview: {pipeline.estimate_duration():.1f}s, ~{pipeline.estimate_output_size() / 1e9:.1f}GB output")
        return

    if not args.apply:
        print("DRY-RUN: Use --apply to execute")
        return

    result = pipeline.run()
    print(f"Complete: {result['files_processed']} files, {result['output_size_mb']:.0f}MB")

if __name__ == "__main__":
    main()
```

## Error Handling

### Recoverable Errors
- **File read failure**: Skip file, log warning, continue
- **Encoding timeout**: Retry with lower bitrate
- **Metadata missing**: Use filename as fallback
- **Disk full**: Partial output + manifest, exit gracefully

### Non-Recoverable Errors
- **No ALAC files found**: Exit with clear error
- **ffmpeg not installed**: Exit with install instructions
- **Output directory inaccessible**: Exit with permission error
